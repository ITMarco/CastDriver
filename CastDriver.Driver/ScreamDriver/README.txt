Place Scream driver files here before building/distributing.

Download the latest release from: https://github.com/duncanthrax/scream/releases

From the release zip, copy:
  Install/driver/x64/   -> x64/
  Install/driver/x86/   -> x86/
  Install/driver/arm64/ -> arm64/

Each folder should contain: Scream.cat, Scream.inf, Scream.sys
